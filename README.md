# Lunar

Godot 4.7.2 / GDScript / 2D 叙事探索与记忆还原游戏。本机项目目录为 `D:/godot/demo/demo2`，仓库名为 `Lunar`。

## 运行与操作

使用 Godot 4.7.2 Mono 打开本目录的 `project.godot`，按 F5 从主菜单运行。项目入口为 `scenes/ui/main_menu.tscn`，菜单在新游戏剧情结束后创建 `main.tscn` 游玩场景。参考画布为 1920×1080。

| 操作 | 输入 |
| --- | --- |
| 移动 | WASD |
| 靠近物件交互 | F；当前目标显示轮廓光晕 |
| 点击查看 | 左键，仅部分物件支持 |
| 普通对白补全或翻页 | 左键、Enter、空格或 F |
| 当前弹层返回 / 探索界面暂停 | Esc |
| 记忆还原 | 左键拖拽月相与词语，Enter 按阶段确认 |

首次创建游玩实例时显示一次键帽操作说明，首个按键用于关闭说明。切换地点、暂停和继续期间保持当前会话。

水井、鱼缸与画室洗笔桶共享每局一次的碎片拖拽引导：按住左键，将月相碎片拖到对应物体上松开。引导显示时可直接拖拽，首块成功投入后淡出；任意非 Esc 按键可收起并消耗该次输入，Esc 仍退出谜题。三处碎片接收区域均覆盖物体外接矩形并保留边缘容错，词语拖回取消使用各自水面范围。

每次新游戏完整播放开场并重建状态；继续游戏恢复当前进程内的位置和进度。关闭或重新运行项目后进度重置。载入游戏、设置、制作人员名单当前为预留页面。

## 当前内容

- 五个相连地点：卧室、二楼走廊、一楼、小院和画室，包含碰撞边界、出生点、门户与场景淡入淡出。
- 卧室照片、走廊照片和画室草稿纸分别提供“港湾”“涌泉”“潮汐”记忆碎片；小院灌木提供画室钥匙，奖励去重。
- 卧室窗户播放五张月相 CG，每张 2 秒；部分室内物件支持点击或 F 查看剧情正文。
- 水井、画室洗笔桶、鱼缸依次对应阶段 1、2、3，共用记忆谜题并按有序词组触发剧情：水井复用已有分段 CG 与后续对白，洗笔桶“港湾→潮汐”播放情节块 2 的完整黑底对白，鱼缸“港湾→涌泉”播放情节块 3 的完整黑底对白；其他已配置组合在原背景上浮现微剧情文字，读完可继续尝试。三处保留原句型、布局与操作，完整映射见项目状态文档。洗笔桶首次进入保留三句前置对白，情节块 2、3 的 CG 图片待提供。
- 画室置物架上的《创世纪》可靠近按 F 阅读，包含第七章引文、头痛震动与 Luna 对白。
- 主菜单标题特效、暂停模糊、按钮反馈、交互光晕、通用对白与主角立绘已接入；部分环境、人物和剧情图片继续使用占位。
- 自由操作界面播放 Hide，水井、鱼缸与洗笔桶谜题含前置剧情、微剧情和 CG 切换 SEEK，退出谜题切回 Hide；暂停与返回菜单冻结音频，继续恢复原位置。整段开场及卧室淡入结束前保持无音乐，主菜单无新增 BGM。

## 开发与交付

当前项目已安装并启用 `addons/godot_ai`。本机 MCP 客户端配置独立于项目，交给组员时复制完整项目或克隆仓库，再导入 `project.godot`。

常规开发不主动运行测试、验证场景或试玩，手工测试由用户进行。用户明确要求测试或修复 bug 时，再根据影响范围选用 `tests/` 中的验证场景；历史验证脚本与当前接口的核对事项见项目状态文档。

三个谜题的碎片中文名与组合剧情映射已按当前文件静态核对；未由 Codex 启动试玩或测试，浮现效果、排版与交互体验待手工验收。画室门继续检查钥匙，进入后不显示“已解锁”。

Hide/SEEK 的原文件归档与导入参数已静态核对，本轮未由 Codex 启动试玩或音频试听；音乐切换及循环听感待用户确认。

保留必要资源、`.uid` 和 `.import` 设置；`.godot/`、`verification/`、日志和本机配置由 `.gitignore` 排除。美术源文件与原始 ZIP 保留在项目外，游戏使用的导出资源通过 `res://` 引用。
