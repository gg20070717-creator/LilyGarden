## 五地点内容

### 卧室

`scenes/bedroom.tscn` 为新游戏探索起点，与二楼走廊相通。已接入地板墙面、边框、门窗、书架、桌椅、床、照片框及台灯素材；台灯为装饰，未提供素材的物件仍保留白模。

- 桌上字条显示“来水井边见我”，默认 4 秒后消失。
- 书架照片显示“照片上的女人背对月光，面目模糊不清”，绑定大图并获得“港湾”。正文打开时立即记入库存；随后为获得提示页，提前 Esc 仍保留奖励，重复查看不重复发放。
- 窗户已配置五张月相 CG，按数组顺序播放，默认每张 2 秒；完整播放或左键/F/Esc 提前退出后返回原处，重新查看从第一张开始。旧文档中的“空白 CG”描述已不符合当前配置。

### 二楼走廊

`scenes/corridor.tscn` 连接卧室、画室与一楼。墙面地板、边框、两扇门、三幅照片框与花盆已接入图片；楼梯及新增水渍等保留白模。下楼从凸出楼梯的上端按 F 触发，上楼返回该端平台，左侧不属于楼梯交互区。

- 右侧记忆照片显示“你搂着某人站在实验室里。照片上，那人的脸庞不知为何被烧了一个洞。”并立即获得“涌泉”；继续采用正文、获得提示两页流程与奖励去重，稳定 ID 保持 `corridor_photo_02`。
- 画室门要求 `studio_key_01`；无钥匙显示 4 秒“已上锁”，持有后进入并保留钥匙，进入后不显示“已解锁”。
- 墙面水渍与落地水洼均可查看“水渍到处都是。这座房子正在被水淹没。”，不发放道具。

### 画室

`scenes/studio.tscn` 为独立房间，返回门通往走廊。画架、凳子、调色板桌、洗笔桶、置物架、窗、散落画框与后墙挂画、报纸、照片保留白模布局。

- 叠放画框旁草稿纸可左键点击或靠近按 F；显示正反面占位图与高中草稿纸正文，立即获得“潮汐”，奖励去重。图片由 `Interactables/CollectSketchPaper.artwork` 替换。
- 画架正文为“月亮。这是她最爱的母题。”。
- 洗笔桶使用记忆类幽蓝光晕，可左键点击或靠近按 F。持有任意匹配碎片时打开独立谜题，首次先播三句前置对白；没有匹配碎片时查看“水面毫无波澜。”。保持“之中有”句型，港湾→潮汐触发情节块 2 的完整黑底对白，其余已配置组合触发微剧情，详见下方映射。
- 置物架的《创世纪》书本可靠近按 F 或直接左键点击，沿用普通物件白色目标光晕；默认五页阅读剧情已接入，详见下文故事时序。

### 一楼

`scenes/first_floor.tscn` 连接走廊和小院。地板墙面、边框、大门、鞋垫与小凳子已接入素材，其他家具以白模为主。两个空房可直接走入；地毯、鞋垫与水渍可踩踏。上楼从楼梯下端按 F 触发，下楼返回该端，左侧不属于楼梯交互区。

- 玄关与客厅的鞋柜、挂画、绿色地毯、鱼缸和四处水渍可点击或靠近按 F 查看；四处水渍分布在左上空房、左侧通道、客厅右侧、帐篷右侧。
- 鞋柜正文涉及玛丽珍鞋和运动鞋；挂画为不认识的漫画角色；地毯正文保留人物对绿色与图案的回忆。鱼缸依据库存进入查看或独立记忆谜题，港湾→涌泉触发情节块 3 的完整黑底对白。
- 厨房餐桌正文描述打开的罐头、空包装袋与未收餐具；储物柜正文描述罐头、压缩饼干和瓶装水；料理台草稿纸正文为引力波方程及“错误”。这些查看不发放或消耗道具。
- 下方房间书柜与窗、餐桌杯盘和杂志、料理台旁废纸篓为当前布局内容。新增草稿纸为无碰撞桌面白模。

### 小院

`scenes/courtyard.tscn` 连接一楼，保留水井、灌木、左侧弯路、后方栏杆、右侧树木落叶、底部灌木与稀疏杂草的白模布局；新增装饰不阻挡通行。

- 水井左侧灌木按 F 立即获得画室钥匙，显示钥匙占位图形和名称；左键/F/Esc 关闭，重复查看不重复发放。
- 水井无对应碎片时显示“水面很平静，毫无波澜”；持有任意配置选项对应的碎片即可进入谜题。集齐两张照片后的首次引导条件另见下节。

## 背景音乐状态

用户提供的 `Hide.wav` 与 `SEEK.wav` 已原样归档至 `assets/audio/bgm/hide.wav`、`seek.wav`，独立清单 `assets/audio/manifest.json` 记录来源、SHA-256、格式与帧数。两轨均为 48 kHz 双声道 PCM32 原文件，5,285,648 帧，约 110.1176667 秒；Godot 采用无压缩运行 PCM16，关闭裁剪、归一化与重采样，使用 `begin 0 / end -1` 全曲 Forward 循环。

常驻 `BGM` 使用一个 AudioStreamPlayer 和 AudioStreamInteractive 的 Hide/Seek 双 clip，双向为 `IMMEDIATE + SAME_POSITION + FADE_CROSS`，`fade_beats = 0.03`；当前无 BPM 的 WAV 对应约 30 ms 逐采样平滑。默认音量为 `-6 dB`、Master bus，可调整控制器导出属性，尚无音量设置页。

| 时机 | 已接入行为 |
| --- | --- |
| 整段开场及卧室淡入结束前 | 无音乐 |
| 自由操作界面 | 首次从 0 开始 Hide |
| 水井/鱼缸/洗笔桶谜题打开 | 同位置切 SEEK，覆盖前置剧情、选碎片、填词、微剧情与 CG；微剧情读完回谜题保持 SEEK |
| `return_started` 或 Esc 关闭 | 同位置切回 Hide，后续普通对白保持 Hide |
| 普通收集、图片及地点切换 | 保持当前 BGM 与播放时间 |
| 暂停或回主菜单 | 冻结音频时间，继续恢复；主菜单无新增 BGM |
| 新游戏 | 重建会话及播放器，开场和淡入结束后从 0 开始 |

原文件归档及参数已静态核对，组合剧情沿用既有谜题音乐生命周期，音轨、音量及切换参数保持现有配置。未由 Codex 启动试玩、验证场景或音频试听；BGM 接入状态为“已实现，待用户试听”。同帧长不证明乐句或循环边界匹配，实际切换听感、音量和循环效果由用户确认后再更新验收状态。音效系统仍待后续方案。

维护与验收采用以下约定：

1. 每次任务写清目标、涉及模块与完成标准，使用“已实现 / 内容待提供 / 候选待排期 / 待核对”等有证据的状态；不把空接口记为完成玩法。
2. 完成改动后说明修改文件、用户可见行为与实际执行的检查。未运行时明确记录；用户手工反馈或授权执行后的结果再更新验收状态。
3. 变更菜单/模态/地点流程时同步 [架构说明](architecture.md)；变更美术路径、区域、字体或导入方式时同步 [美术资产规范](art_assets.md) 与美术清单，变更音轨、循环或切换规则时同步 [音频资源规范](audio_assets.md) 与音频清单；变更玩法、故事时序、ID 或待办状态时同步本页与 README 入口说明。
4. 改动代理工作约束时更新 [AGENTS.md](../AGENTS.md)，保持本页的测试偏好一致。文档以当前代码和用户确认内容为依据，遇到历史描述差异先注明证据和待核对范围。
5. 交付项目复制完整 demo2，并导入其 `project.godot`；运行素材使用项目内 `res://` 路径。编辑器插件随项目保留，本机 MCP 连接配置与团队美术源文件分别管理。
